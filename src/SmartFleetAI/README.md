# SmartFleet AI
## Supply Chain Disruption Assistant & Fleet Utilisation Optimizer

SmartFleet AI is a student hackathon prototype that helps logistics managers monitor fleet utilisation, identify disruption impact, and receive AI-style recommendations for vehicle reassignment.

### Core Features
- Fleet utilisation dashboard
- Vehicle and delivery monitoring
- Supply-chain disruption alerts
- Affected-delivery analysis
- Vehicle reassignment recommendations
- AI assistant for common logistics questions
- Sample data for demonstration

### Prototype Technology
- HTML
- CSS
- JavaScript
- JSON sample data
- Client-side recommendation engine

### Demo Scenario
A high-severity road disruption affects the Ahmedabad-Surat route. SmartFleet AI identifies affected deliveries and recommends an available, underutilised vehicle with enough capacity.

### Important
This is a hackathon prototype. The recommendation engine is implemented locally so the application can run without external credentials. The IBM BoB/LLM integration point can be connected later according to the official hackathon environment and user guide.

### Project Structure
- `app/` - working web application
- `data/` - sample fleet, delivery and disruption data
- `documentation/` - project documentation
- `demo/` - demo script
- `presentation/` - presentation content
- `screenshots/` - place final screenshots here

### Run
Open `app/index.html` in a modern browser.
For best results, run it through a simple local web server if your environment blocks local file access.
